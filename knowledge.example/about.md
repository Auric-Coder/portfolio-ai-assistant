# About Arlo

Arlo Quill is a **fictional** sample persona used to demonstrate this assistant. Nothing here describes a real person.

Arlo is a third-year B.Tech student in Computer Science (Data Systems) at the fictional Harrowgate Institute of Technology. He likes building small, honest tools: a flood-sensor dashboard, a note-taking app with search, and a chess-clock for study sessions.

Arlo is looking for a summer internship in data engineering or applied machine learning, ideally on a team that values clear writing and well-tested code.

## What he is like to work with

- Writes the README before the code, and updates it when the code changes.
- Prefers small pull requests and boring, readable solutions.
- Keeps a public changelog for every project.
