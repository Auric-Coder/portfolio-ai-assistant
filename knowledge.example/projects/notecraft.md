# NoteCraft (notes app with search)

NoteCraft is a fictional note-taking web app focused on fast full-text search.

## Features
- Markdown notes with tags and backlinks.
- Full-text search built on SQLite's FTS5 index, with highlighted snippets.
- Keyboard-first navigation.

## Status
In progress. Search and tagging work; sync between devices is not built yet and no release has been made. It has no public demo.
